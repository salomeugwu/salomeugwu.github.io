# Salome Ugwu Portfolio

A free, static, one-page professional portfolio for Salome Sopuruchukwu Ugwu.

## Files
- `index.html` — website content
- `style.css` — responsive design and dark mode
- `script.js` — navigation, theme toggle and reveal animations
- `assets/` — professional photos and certificates

## Free hosting
This site has no database, paid CMS, paid form provider, or subscription dependency.

### GitHub Pages
1. Create a free GitHub account at https://github.com/ if needed.
2. Create a new public repository named `salomeugwu.github.io` (the repository name is optional; this exact name gives the cleanest free Pages address).
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
4. In the repository, open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main`, and save.
6. GitHub will publish the site at your free `https://salomeugwu.github.io/` address if the repository uses that name.

No custom domain is required.
